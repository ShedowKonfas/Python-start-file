# start_work

Одноразовый генератор заготовки Python-проекта под Windows. В репозитории один файл — `start_work.bat`.

## Что делает

При запуске из нужной папки скрипт:

1. Создаёт (перезаписывает!) пустые `main.py` и `requirements.txt` через `echo. >`.
2. Генерирует `start.cmd` с запуском `venv\Scripts\python.exe main.py` и `pause`.
3. Выполняет `py -m venv venv`.
4. **Удаляет сам себя**: `del "%~f0"`.

## Как пользоваться

Запускать только в пустой папке и только когда заготовка действительно нужна:

```bat
start_work.bat
```

После этого останутся `main.py`, `requirements.txt`, `start.cmd` и `venv\`; самого `start_work.bat` не будет.

## Внимание

- Не запускайте батник «просто посмотреть»: он удалит себя, а существующие `main.py`, `requirements.txt`, `start.cmd` перезапишет.
- Чтобы изучить логику — откройте файл в текстовом редакторе, а не запускайте.
- Требуется Windows и `py` (Python Launcher) в PATH.

## Тесты

Автотестов нет; проект — один батник-генератор.

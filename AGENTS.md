# AGENTS.md — start_work
## Назначение
Одноразовый .bat-генератор болванки Python-проекта: `main.py`, `requirements.txt`, `start.cmd`, `venv`. Больше в репозитории нет ничего.
## Карта файлов
- `start_work.bat` — создаёт заготовки, генерирует `start.cmd`, вызывает `py -m venv venv`, затем удаляет себя (`del "%~f0"`).
- `README.md`, `AGENTS.md` — документация (батником не затрагиваются).
## Запуск и тесты
```bat
start_work.bat
```
Только в пустой папке и только по явной просьбе. Тестов нет; проверка логики — чтение файла, не запуск.
## Соглашения
- Нужен Windows и Python Launcher (`py`) в PATH.
- Комментарии в батнике — на русском; набор файлов менять только по просьбе.
- Документация обязана предупреждать о самоудалении и перезаписи файлов.
## Подводные камни
- `del "%~f0"` удаляет запущенный батник — штатное, но необратимое поведение.
- `echo. > main.py` перезаписывает существующие файлы без запроса.
- Сгенерированный `start.cmd` требует venv.
## Запреты
- **Не запускать `start_work.bat` без явной просьбы пользователя** — он удалит себя и перезапишет файлы.
- Не удалять файлы и папки без явного разрешения пользователя.
- Не трогать системные файлы.
- Не выдумывать тесты и не создавать «заготовки для проверки»; не делать commit/push без просьбы.
